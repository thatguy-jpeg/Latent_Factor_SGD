Latent factor models and SGD

Predict missing movie ratings with R ≈ Q·Pᵀ. Drag vectors, step through SGD, tune the sliders, and watch train vs test error.

How to use (60 seconds)
  1. Click ⏩ 50 epochs. The model learns.
  2. Look at the plot. Each dot is a movie. Each arrow is a user.
  3. Drag a dot or an arrow tip. Watch r̂ change in the readout and in the matrix.
  4. Click Step. The stepper shows which rating SGD used and how q and p moved.
  5. Click Overfit preset. Click ⏩ 50 epochs two times. Compare the two lines in the chart.

The model

r̂xi = μ + qi · px = μ + Σf=1k qif pxf
εxi = rxi − r̂xi
qi ← qi + η ( ε px − λ qi )
px ← px + η ( ε qi − λ px )
Objective: min Σ(x,i)∈train (rxi − r̂xi)² + λ ( Σi ‖qi‖² + Σx ‖px‖² )

q = movie vector · p = user vector · ε = error · η = learning rate · λ = regularization · μ = mean train rating (optional, see Controls). The factor 2 from the derivative is folded into η. The slides use λ₁ and λ₂; this page uses one λ for both.

1 · Ratings matrix (8 users × 10 movies)

Big number = actual rating. Small gray number = model prediction r̂. Red tint = size of error. Dashed blue border = test rating (held out, SGD never sees it). “–” = unrated. Click a cell to inspect it.

Changing k or the μ box restarts training. Changing η or λ does not. You can change them in the middle of a run.

2 · Drag the vectors

Prediction = q·p = (length of the orange projection) × ‖p‖. The orange bar is the projection of the movie onto the user's arrow. A long arrow makes the projection count more.

3 · SGD stepper

Training diverged (values blew up). Lower η, then click Reset.

4 · Train vs test error (RMSE per epoch)

Pin a run, change a slider, restart, and compare. Test RMSE is measured on only 10 ratings, so small moves (±0.05) are noise.

What to try

  • Good fit: Good preset → ⏩ 50 epochs. Train and test both fall.
  • Overfit: Overfit preset → ⏩ 50 epochs twice. Train RMSE goes near 0. Test RMSE stays high or rises. The model has 144 numbers (18 vectors × 8) for only 38 training ratings. It memorizes.
  • Regularize: Keep k=8. Raise λ to 0.3. Train error rises, test error drops. The gap shrinks.
  • Learning rate: Set η to 0.1. The curve gets noisy. Small η is smooth but slow.

Exam recap

  • R ≈ Q·Pᵀ. Each row of Q is a movie (item) vector. Each row of P is a user vector. Missing rating = dot product.
  • Fit only on known ratings. Minimize SSE + regularization (“error” + λ “length”).
  • Too many factors with no regularization fits noise. This is overfitting. Test error rises for k beyond the real structure.
  • GD uses all ratings per step. SGD uses one rating per step. SGD is noisier but much faster in practice.

Honest notes. The ratings are synthetic. They were made from 2 hidden taste dimensions plus noise, so k=2 fits best here by design. Real data has no known right k. The two axes the model learns can be any rotation of “male/female” and “serious/funny”. Do not expect labeled axes. With k=1 the plot has only a horizontal axis.
